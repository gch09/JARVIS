# JARVIS — 윈도우 음성 비서 (v14.3)

영화 아이언맨의 자비스처럼, 말로 컴퓨터를 조작할 수 있는 윈도우용 음성 비서입니다.
파이썬으로 만든 로컬 서버(`jarvis_server.py`)와 브라우저에서 보는 대시보드(`jarvis.html`)로 구성되어 있습니다.

## 주요 기능
- **음성 명령**: 프로그램·폴더·웹사이트 열기, 검색, 프로그램 종료, 볼륨 조절과 음소거, 윈도우 설정 열기
- **AI 대화**: Claude Sonnet으로 대화하고, 연결이 안 되면 Groq로 자동 전환합니다. 한국어·영어·일본어·중국어로 대답할 수 있습니다.
- **음성 인식**: Groq Whisper로 말을 글자로 바꾸고, 잡음 때문에 잘못 알아듣는 경우를 걸러냅니다.
- **음성 출력**: Microsoft Edge 신경망 음성을 사용합니다 (한국어 InJoon, 영어 Eric).
- **화자 인증**: 미리 등록한 사용자의 목소리에만 반응합니다. 목소리 분석은 PC 안에서만 이루어집니다 (sherpa-onnx).
- **미니 게임**: 주사위·동전·룰렛(화면 애니메이션 포함), 가위바위보, 퀴즈, 아재개그
- **생활 정보**: 날씨, 환율, 주가, 현재 시간
- **체험 모드**: 행사 부스에서 방문객이 써 볼 수 있는 모드입니다. 위험한 명령은 막고, 체험 모드를 끌 때는 비밀번호가 필요합니다.
- **핸드폰 연결**: 같은 와이파이에 있는 핸드폰으로 접속해 핸드폰을 마이크처럼 쓸 수 있습니다.
- **종료 명령**: "셧다운"이라고 하면 자비스만 꺼지고, "전원 꺼"라고 하면 컴퓨터가 꺼집니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `jarvis_server.py` | 명령을 실제로 실행하는 로컬 서버 (http://localhost:5005) |
| `jarvis.html` | 화면에 표시되는 자비스 대시보드 |
| `jarvis_wake.py` | "Hey Jarvis" 호출어를 백그라운드에서 감지 |
| `start_jarvis.bat` | 더블클릭으로 실행 (오류로 꺼지면 자동으로 다시 시작) |
| `requirements.txt` | 필요한 파이썬 패키지 목록 |
| `boss_info.example.json` | 사용자 소개 설정 예시 |

## 설치 방법
1. [Python](https://www.python.org/downloads/)을 설치합니다. 설치 화면에서 "Add python.exe to PATH"를 꼭 체크하세요.
2. 필요한 패키지를 설치합니다.
   ```
   pip install -r requirements.txt
   ```
3. API 키 파일을 만듭니다. 프로젝트 폴더에 아래 파일을 만들고, 파일 안에 키 한 줄만 붙여 넣으면 됩니다.
   | 파일 | 용도 | 필요 여부 |
   |---|---|---|
   | `groq_key.txt` | 음성 인식(Whisper), 예비 대화 AI | **필수** |
   | `claude_key.txt` | 기본 대화 AI (Claude) | 선택 |
   | `gemini_key.txt` | 여러 명령을 한 번에 말했을 때 나눠서 처리 (예: "유튜브 틀고 소리 줄여줘") | 선택 |

   > 키 파일은 `.gitignore`에 등록되어 있어 깃허브에 올라가지 않습니다. 직접 올리지 않도록 주의하세요.

4. (선택) 사용자 소개를 설정합니다. `boss_info.example.json`을 복사해서 이름을 `boss_info.json`으로 바꾸고 내용을 수정하세요.
   - `intro`: "보스 소개해 줘"라고 했을 때 자비스가 말하는 소개 문장
   - `profile`: 대화 AI가 참고하는 사용자 정보
   - `secret_names`, `affiliation_patterns`, `affiliation_words`, `affiliation_replace`: 체험 모드에서 대답에 나오지 않도록 가릴 이름과 소속, 가린 자리에 넣을 말

   `boss_info.json`은 깃허브에 올라가지 않습니다. 이 파일이 없으면 개인 정보가 없는 기본 소개를 사용합니다.

5. 브라우저는 Chrome 또는 Edge를 권장합니다.

## 실행 방법
`start_jarvis.bat`을 더블클릭하면 서버가 켜지고 대시보드가 열립니다.

처음 실행할 때 화자 인증 모델(약 28MB)과 호출어 감지 모델을 자동으로 내려받습니다.

### 핸드폰으로 연결하기
1. PC와 핸드폰을 같은 와이파이에 연결합니다.
2. 자비스를 켜면 콘솔 창에 `📱 핸드폰 연결: https://…:5006` 주소가 나옵니다. 이 주소를 핸드폰 브라우저에 입력하세요.
3. 보안 경고가 나오면 "고급" → "계속"을 누릅니다. PC가 직접 만든 인증서를 쓰기 때문에 나오는 경고입니다.
4. 체험 모드 비밀번호로 로그인한 뒤 "시스템 시작"을 누르고 마이크 사용을 허용합니다.

와이파이가 바뀌면 PC의 IP 주소도 바뀌므로, 콘솔 창에서 새 주소를 확인하세요.
공용 와이파이처럼 기기끼리의 연결을 막아 둔 곳에서는 핸드폰 핫스팟을 사용하면 됩니다.

## 보안
- 서버는 이 PC(localhost)에서 보낸 명령만 받습니다. Host·Origin 검사와 토큰으로 다른 사이트에서 보낸 요청을 차단합니다.
- 핸드폰 연결은 사설 IP에서만 허용하며, HTTPS·비밀번호 로그인·HttpOnly 쿠키 세션을 사용합니다. 비밀번호를 5번 틀리면 5분 동안 로그인이 잠깁니다.
- 체험 모드 비밀번호는 원문이 아닌 PBKDF2 해시로만 저장합니다.
- API 키, 비밀번호, 인증서, 목소리 데이터, 대화 기록, 개인 정보 파일은 `.gitignore`로 저장소에서 제외했습니다.
