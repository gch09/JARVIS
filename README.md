# JARVIS — 윈도우 음성 비서 (v14.2)

아이언맨의 자비스처럼 말로 컴퓨터를 다루는 윈도우용 음성 비서입니다.
파이썬 서버(`jarvis_server.py`)와 브라우저 대시보드(`jarvis.html`)로 이루어져 있습니다.

## 주요 기능
- **음성 명령**: 프로그램·폴더·웹사이트 열기, 검색, 프로그램 종료, 볼륨·음소거, 윈도우 설정 열기
- **대화**: Claude Sonnet 두뇌 (안 되면 Groq로 자동 전환), 한국어·영어·일본어·중국어 답변
- **받아쓰기**: Groq Whisper + 잡음 제거, 아무도 말 안 했을 때 생기는 헛인식 걸러내기
- **목소리**: Edge 신경망 음성 (한국어 InJoon, 영어 Eric)
- **화자 인증**: 등록한 보스 목소리만 알아듣기 (sherpa-onnx, 목소리는 PC 밖으로 안 나감)
- **놀이**: 주사위·동전·룰렛 애니메이션, 가위바위보, 퀴즈, 아재개그
- **정보**: 날씨, 환율, 주가, 시간
- **체험 모드**: 부스 방문객용 모드. 위험한 명령은 막고, 끌 때 비밀번호 필요
- **핸드폰 연결**: 같은 와이파이의 폰에서 `https://PC-IP:5006` 으로 접속해 폰을 마이크로 사용
- **셧다운 / 전원꺼**: "셧다운"은 자비스만 끄고, "전원꺼"는 컴퓨터를 끔

## 파일 구성
| 파일 | 설명 |
|---|---|
| `jarvis_server.py` | 명령을 실제로 실행하는 로컬 서버 (http://localhost:5005) |
| `jarvis.html` | 화면에 보이는 자비스 대시보드 |
| `jarvis_wake.py` | "hey jarvis" 백그라운드 감지 |
| `start_jarvis.bat` | 더블클릭으로 실행 (오류로 꺼지면 자동 재시작) |
| `requirements.txt` | 파이썬 패키지 목록 |
| `boss_info.example.json` | 보스 소개·개인 정보 설정 예시 |

## 설치
1. [Python](https://www.python.org/downloads/) 설치 ("Add python.exe to PATH" 체크)
2. 패키지 설치
   ```
   pip install -r requirements.txt
   ```
3. API 키 파일 만들기. 이 폴더에 아래 파일을 만들고 키만 한 줄로 붙여 넣습니다.
   | 파일 | 용도 |
   |---|---|
   | `groq_key.txt` | 받아쓰기(Whisper) + 대화 대체 두뇌 — **필수** |
   | `claude_key.txt` | 대화 두뇌 (Claude) — 선택 |
   | `gemini_key.txt` | 한 번에 여러 명령을 말했을 때 나누기 ("유튜브 틀고 소리 줄여줘") — 선택 |

   > 키 파일은 `.gitignore`에 들어 있어서 깃허브에 올라가지 않습니다. 절대 직접 올리지 마세요.

4. (선택) 보스 소개 설정. `boss_info.example.json`을 복사해 `boss_info.json`으로 이름을 바꾸고 내용을 고칩니다.
   - `intro`: "보스 소개해줘" 하면 말하는 소개
   - `profile`: 대화 AI가 알고 있을 보스 정보
   - `secret_names`, `affiliation_patterns`, `affiliation_words`: 체험 모드에서 대답에 나오지 않게 가릴 이름·소속

   `boss_info.json`은 깃허브에 올라가지 않습니다. 없으면 개인 정보 없는 기본 소개를 씁니다.

5. 브라우저는 Chrome 또는 Edge를 권장합니다.

## 실행
`start_jarvis.bat` 을 더블클릭하면 서버가 켜지고 대시보드가 열립니다.

화자 인증 모델(약 28MB)과 웨이크 워드 모델은 처음 실행할 때 자동으로 내려받습니다.

### 핸드폰 연결
1. PC와 폰을 같은 와이파이에 연결
2. 콘솔에 나오는 `📱 핸드폰 연결: https://…:5006` 주소를 폰 브라우저에 입력
3. 인증서 경고가 나오면 고급 → 계속 (PC가 직접 만든 인증서라서 나오는 경고)
4. 체험 모드 비밀번호로 로그인 → 시스템 시작 → 마이크 허용

와이파이가 바뀌면 PC IP도 바뀌므로 콘솔에서 새 주소를 확인하세요.
학교 와이파이처럼 기기끼리 통신을 막는 곳에서는 폰 핫스팟을 쓰면 됩니다.

## 보안
- 서버는 이 PC(localhost)에서만 명령을 받습니다. Host·Origin 검사와 토큰으로 다른 사이트의 요청을 막습니다.
- 폰 연결은 사설 IP만 허용하고, https + 비밀번호 로그인 + HttpOnly 쿠키 세션을 사용합니다. 5번 틀리면 5분 동안 잠깁니다.
- 체험 모드 비밀번호는 PBKDF2 해시로만 저장합니다 (`guest_password.json`, 깃허브에 안 올라감).
- API 키, 비밀번호, 인증서, 목소리 정보, 대화 기록, 보스 개인 정보는 `.gitignore`로 저장소에서 빠져 있습니다.
